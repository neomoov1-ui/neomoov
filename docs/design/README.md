## Canevas en ligne

« Neomoov : design des applications » : https://claude.ai/artifact/EwhoGryiRhAWpzmR362u8z

Le canevas est privé : seul le compte du fondateur l'ouvre. Il ne contient que des écrans d'interface avec des données fictives. Il ne contient ni le document de référence, ni le modèle financier, ni aucune donnée des captures Uber.

## État au 22 septembre 2026 : lot 1, 20 maquettes

| Page du canevas | Maquettes |
|---|---|
| Fondations | Couleurs, typographie, boutons, états, mode sombre |
| Application client | Accueil et connexion, carte et destination, catégorie et prix, suivi du chauffeur, fin de course |
| Application chauffeur | Accueil en ligne, offre de course, attente du client, revenus, courses planifiées, packs, documents |
| My Hub | Tableau de bord en temps réel |
| Réservation web | Page de réservation publique |
| Relevé hebdomadaire | Trois pages, format lettre, spécimen |
| Récapitulatif mensuel | Deux pages, format lettre, spécimen |

Toutes les valeurs affichées viennent du cahier des charges : grille tarifaire, exemple de contrôle à 31,56 $, forfaits aéroport, packs. Les relevés sont des spécimens dont les totaux sont justes.

Le logo est provisoire. Les maquettes n'ont pas été contrôlées à l'écran par Claude : le premier regard est celui du fondateur.

## Modifier le canevas

Depuis le workspace Jarvis, demander à Claude : « Modifie la maquette X du canevas Neomoov ». Claude relit d'abord la version en ligne, car le fondateur peut l'avoir modifiée à la main dans l'éditeur.
