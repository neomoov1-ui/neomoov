3. INSCRIPTION ET ESPACE GRATUIT
POST avec nonce nma_action ; champs prénom obligatoire max80 et email obligatoire max190 ; orientation hidden, vérifiée contre quatre slugs ; consentement case non cochée par défaut ; champ website honeypot ; plafond 5 tentatives/heure par clé dérivée d'IP via HMAC avec sel WP.
Compte WordPress rôle subscriber, login academy_ + 16 caractères aléatoires, mot de passe initial aléatoire32. Notification native wp_new_user_notification user pour définir mot de passe. Une demande avec adresse déjà existante conserve compte et consentement existants ; réponse générique pour ne pas divulguer l'existence du compte.
Métadonnées : nma_track, nma_consent yes/no, nma_consent_date UTC. Pas de champ profil distinct, pas de version du texte de consentement, pas de source UTM persistée dans ce code. Ajouter version et preuve détaillée constitue une amélioration future.
Connexion et mot de passe oublié utilisent les fonctions natives WordPress avec retour membre ou formation ; pas de système d'authentification parallèle. Les routes membre/formation affichent un écran de connexion aux visiteurs.
Un membre gratuit dispose du compagnon, des fiches, sauvegarde des bilans et bouton de retrait du consentement commercial. L'offre payante apparaît dans l'espace si ventes ouvertes. Aucun paiement n'est effectué par la création du compte.
Les bilans reçus par POST exigent connexion et nonce ; receipts/costs/hours/km numériques 0..10000000, heures et km >0 ; date UTC ; nma_balances garde les 100 derniers (ordre récent d'abord), interface affiche 30. Aucun outil de suppression individuelle de bilan visible dans cette version ; demandes données par email support.
